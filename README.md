# Player Engagement Prediction

Классификация уровня вовлечённости онлайн-игроков (**Low / Medium / High**) на основе их поведенческих метрик. Сравнение трёх моделей машинного обучения и анализ ключевых факторов, влияющих на вовлечённость.

## О проекте

Проект решает задачу многоклассовой классификации: по данным об игровой активности предсказать, насколько игрок вовлечён в игру. Это может применяться для:

- сегментации игроков и персонализации контента;
- выявления «затухающих» игроков (churn prediction);
- таргетирования маркетинговых кампаний

## Данные

Датасет: [Predict Online Gaming Behavior Dataset](https://www.kaggle.com/datasets/rabieelkharoua/predict-online-gaming-behavior-dataset) (Kaggle)

- **40 034** записи, **13** исходных признаков
- Целевая переменная: `EngagementLevel` — 3 класса
  - `Low` — 10 324
  - `Medium` — 19 374
  - `High` — 10 336

### Признаки

| Признак | Тип | Описание |
|---|---|---|
| `PlayerID` | int | ID игрока (удалён из обучения) |
| `Age` | int | Возраст |
| `Gender` | cat | Пол |
| `Location` | cat | Регион |
| `GameGenre` | cat | Жанр игры |
| `PlayTimeHours` | float | Часов в игре |
| `InGamePurchases` | bin | Внутриигровые покупки (0/1) |
| `GameDifficulty` | ord | Сложность (Easy/Medium/Hard) |
| `SessionsPerWeek` | int | Сессий в неделю |
| `AvgSessionDurationMinutes` | int | Средняя длительность сессии |
| `PlayerLevel` | int | Уровень игрока |
| `AchievementsUnlocked` | int | Открыто достижений |

## Пайплайн

1. **Загрузка данных** через `kagglehub`
2. **Кодирование категориальных признаков**
   - Порядковые (`EngagementLevel`, `GameDifficulty`) → ручной маппинг в `0-2` (осознанный отказ от One-Hot, т.к. между классами есть естественный порядок (ранжирование))
   - Номинальные (`Location`, `GameGenre`, `Gender`) → One-Hot Encoding
3. **Разделение train/test** — 80/20, `random_state=42`
4. **Масштабирование** — `StandardScaler` (для логистической регрессии)
5. **Корреляционный анализ** относительно целевой переменной
6. **Обучение 3 моделей**
7. **Оценка** по метрике `f1_score(average="macro")`
8. **Анализ важности признаков** и матрицы ошибок

## Модели и результаты

| Модель | F1-macro |
|---|---|
| Logistic Regression | 0.8142 |
| Decision Tree | 0.8176 |
| **Random Forest (`class_weight="balanced"`)** | **0.8993** |

**Победитель:** Random Forest со сбалансированными весами классов — прирост **+8.8%** к логистической регрессии и **+8.2%** к дереву решений. Время обучения дольше (~3.1 сек против 0.1 сек), но для данного датасета это приемлемо.

### Главные инсайты

- **Частота и длительность сессий** — доминирующие предикторы вовлечённости. Вместо общего времени в игре (`PlayTimeHours`) куда важнее то, **как часто** и **как долго** игрок играет за один заход.
- `AchievementsUnlocked` и `PlayerLevel` дают слабый, но ненулевой вклад — прогресс в игре слегка коррелирует с вовлечённостью.
- **Демография (пол, регион) и жанр игры** практически не влияют на целевую переменную — различия между игроками кроются в их поведении, а не в профиле.
- Confusion matrix показала, что основная путаница — между соседними классами (`Low`↔`Medium`, `Medium`↔`High`), что ожидаемо для порядковой шкалы.
